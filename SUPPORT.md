# Support

ThreatFade Web is the public website, documentation, research and evaluation interface for the ThreatFade engine.

## Where to get help

| Need                                | Best channel                                                                                                            |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Installation or usage question      | [Engine repository discussions](https://github.com/LloydCoder/tinlance-threatfade/discussions), when enabled            |
| Website defect                      | [Open a bug report](https://github.com/LloydCoder/tinlance-threatfade-web/issues/new?template=bug_report.yml)           |
| Documentation correction            | [Open an issue](https://github.com/LloydCoder/tinlance-threatfade-web/issues)                                           |
| Feature proposal                    | [Open a feature request](https://github.com/LloydCoder/tinlance-threatfade-web/issues/new?template=feature_request.yml) |
| Commercial or enterprise evaluation | [ThreatFade contact page](https://threatfade.com/contact)                                                               |
| Security vulnerability              | Follow [SECURITY.md](SECURITY.md) and email security@tinlance.com                                                       |

## Before asking

Please include the relevant route or documentation page, browser and operating-system versions, the web repository commit or deployment version, expected behavior, actual behavior, and concise reproduction steps. Redact tokens, personal information, customer data and security telemetry.

For engine behavior, include the engine version and consult the [engine repository](https://github.com/LloydCoder/tinlance-threatfade). The web repository does not independently define detection behavior.

## Support boundaries

This project is open source. Public issue response and community support are provided on a best-effort basis; no response time or service-level agreement is implied. Contractual support, managed services and enterprise response commitments require a separate written agreement.

Please do not post vulnerability details or sensitive evidence publicly.
