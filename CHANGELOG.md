# Changelog

All notable changes to ThreatFade Web are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow the project's release process. This web repository is versioned independently from the ThreatFade engine.

## [Unreleased]

### Added
- Community health guidance, structured issue forms and a pull-request template.
- Documentation navigation, configuration reference and LLM-friendly project index.
- Repository metadata, release and branch-protection guidance.

### Changed
- Clarified the web repository's MIT license boundary versus the engine repository's Apache-2.0 license.
- Aligned Node.js onboarding requirements with the package engine constraint.
- Improved public documentation discoverability and brand guidance.

### Fixed
- Corrected the website license metadata to match the repository's MIT license.
- Removed misleading static sitemap modification timestamps from routes without source-level update metadata.
